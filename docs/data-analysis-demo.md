分析任务指令 (Analysis Instructions)请按以下步骤逐步执行分析，不要跳过任何一步：

第一步：数据清洗与异常检测 (Data Cleaning & Anomaly Detection)
提取关键指标：从数据库中提取所有门店的核心数据，构建对比视图。
识别红线指标：标记出以下高危信号：
    非异率/商责订单 > 0 (特别是连续出现)
    1分钟/5分钟回复率 连续 > 2天不合格
    店铺评分 < 4.5 (或环比下降 > 0.2)
    食安/服务负反馈 提及次数 > 1
计算衍生指标：估算“流量 - 转化 - 复购”链条中的断点（例如：曝光高但下单少 = 菜单/价格问题；下单多但实收低 = 活动力度过大/毛利失控）。

第二步：多维度诊断 (Multi-dimensional Diagnosis)
对每家门店进行“红/黄/绿”灯评级，并回答以下问题：
财务健康度：到手率是否低于行业基准（如 55%）？实收增长是源于单量增加还是客单价提升？是否存在“增收不增利”？
运营合规性：非异率产生的具体原因是什么？（商家误操作 vs 骑手问题 vs 顾客恶意）。回复率低下是由于人手不足还是管理疏忽？
口碑与质量：差评的具体内容归类（口味、包装、食安、服务）。是否存在系统性风险（如多家店同时出现“食安”投诉）？
活动有效性：本周的活动（如神会员、返佣）是否带来了预期的 ROI？是否有副作用（如拉低评分、增加商责）？

第三步：根因分析与关联挖掘 (Root Cause Analysis)
关联分析：寻找指标间的因果关系。
   示例：评分下降 -> 导致曝光权重降低 -> 导致实收下滑。
   示例：出餐上报不及时 -> 导致骑手等待/取消 -> 导致非异率上升。
案例深挖：针对输入中提到的具体案例（如“骑手拿错餐直接告知顾客”），分析其背后的 SOP 漏洞。

第四步：生成行动建议 (Actionable Recommendations)
为每家“红灯/黄灯”门店生成具体的SMART行动计划：
紧急止损 (P0)：针对商责、食安、严重违规的立即整改措施。
短期优化 (P1)：针对回复率、评分、活动配置的调整方案。
长期策略 (P2)：针对菜单结构、成本控制、人员培训的规划。
