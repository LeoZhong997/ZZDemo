## 概述

简化版门店映射系统直接从 `daily_orders` 表中读取品牌门店名称与平台门店名称的映射关系，无需额外的映射表和配置。

### 为什么需要门店映射？

三个外卖平台（美团、饿了么、京东）对同一门店可能使用不同的名称：

| 品牌门店名称 | 美团平台名称 | 饿了么平台名称 | 京东平台名称 |
|-------------|-------------|---------------|-------------|
| 信和店 | 雪乡情大地锅(信和广场店) | 雪乡情铁锅炖(信和广场店) | 雪乡情铁锅炖（信和广场店） |
| 塘朗店 | 雪乡情东北菜（塘朗店） | 雪乡情东北菜(塘朗店) | 雪乡情东北菜（塘朗店） |

门店映射系统帮助统一管理这些映射关系，实现跨平台数据汇总分析。

## 核心功能

### 1. 自动提取映射关系

- 直接从已有的 `daily_orders` 表读取
- 自动识别品牌门店名称 (`brand_store_name`) 和平台门店名称 (`platform_store_name`)
- 按平台分类展示映射关系

### 2. 日期范围筛选

- 可选择任意日期范围查看映射关系
- 显示每个映射关系的首次和最后出现日期

### 3. 多平台支持

- 支持美团、饿了么、京东三大平台
- 按平台分标签页展示
- 统计每个品牌门店的记录数

### 4. 数据导出

- 支持导出所有映射关系 (CSV格式)
- 支持按平台分别导出
- 包含完整的映射信息和统计数据

## 使用方法

### 方法1: 通过主页面导航

1. 打开外卖数据看板主页
2. 滚动到页面底部
3. 点击 "🔗 门店映射" 按钮
4. 自动跳转到门店映射页面

```bash
streamlit run app.py
```

然后在左侧边栏选择 "store_mapping_simple"

## 页面功能说明

### 1. 统计信息卡片

显示四个关键指标：

| 指标 | 说明 |
|------|------|
| 总映射数 | 当前日期范围内的映射关系总数 |
| 品牌门店数 | 不重复的品牌门店数量 |
| 平台数 | 涉及平台数量 |
| 总记录数 | 相关记录的总数 |

### 2. 日期范围选择（侧边栏）

- 开始日期：查询的起始日期
- 结束日期：查询的结束日期

### 3. 各平台映射关系

按平台分标签页显示：

- **品牌门店名称**: 统一的品牌门店标识
- **平台门店名称**: 该平台下的实际门店名称
- **记录数**: 该映射关系的记录数量
- **首次出现/最后出现**: 时间范围信息

### 4. 数据导出

提供多个导出选项：

- 导出所有映射关系（CSV）
- 按平台分别导出（每个平台一个CSV文件）

## 最佳实践

### 1. 定期查看映射关系

- 建议每周检查一次
- 确保新门店的映射正确
- 及时发现异常映射

### 2. 导出备份映射关系

- 定期导出映射数据作为备份
- 保存不同时期的映射记录
- 便于追溯历史变化

### 3. 修正源文件错误

- 发现映射错误时，在源文件中修正
- 重新导入数据以更新映射
- 验证修正后的映射关系

### 4. 使用合理的时间范围

- 查看当前活跃门店：选择最近7-14天
- 查看历史映射：选择更长时间范围
- 避免选择无数据的日期范围

## 常见问题

### Q1: 映射关系有误怎么办？

映射关系完全来源于实际导入的数据。如果映射有误：

1. 在源 Excel/CSV 文件中修正门店名称
2. 重新运行 ETL 导入数据
3. 验证映射关系是否已更新

### Q2: 一个品牌门店对应多个平台门店名称？

这是正常情况。例如：
- "信和店" 在美团对应 "雪乡情大地锅(信和广场店)" 和 "雪乡情铁锅炖(信和广场店)"

系统会自动识别并展示所有映射关系。

### Q3: 新门店如何添加映射？

新门店不需要手动添加映射。当 ETL 导入包含新门店的数据时，系统会自动：
1. 识别平台门店名称
2. 根据配置的映射规则确定品牌门店名称
3. 将映射关系存入数据库

### Q4: 如何查看历史映射？

调整日期范围选择器，选择需要查看的历史时期即可。

## 技术说明

### 数据来源

- 映射关系完全来源于实际导入的数据
- 不需要手动配置或维护映射表
- 自动从 `daily_orders` 表提取

### 相关文件

| 文件 | 说明 |
|------|------|
| `pages/store_mapping_simple.py` | 门店映射页面 |
| `etl/core/store_mapper.py` | 门店映射处理模块 |

### 数据库查询

```sql
-- 查看所有映射关系
SELECT DISTINCT 
    brand_store_name,
    platform,
    platform_store_name,
    COUNT(*) as record_count,
    MIN(date) as first_appearance,
    MAX(date) as last_appearance
FROM daily_orders
GROUP BY brand_store_name, platform, platform_store_name
ORDER BY platform, brand_store_name;
```
